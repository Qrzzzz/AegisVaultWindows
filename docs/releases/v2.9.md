# AegisVault 2.9

Product version: **2.9**; Windows assembly/PE: **2.9.0.0**. Release candidate; publication and manual accessibility acceptance are tracked separately.

- Integrates reviewed dependency PRs #28–#31: configure-pages 6.0.0, setup-node 7.0.0, deploy-pages 5.0.1 and upload-pages-artifact 5.0.0, pinned to commit SHAs.
- File queues support native arrow navigation and Delete on a focused row. Tab reaches row actions and output details; buttons retain Enter/Space activation. Removing an entry restores focus to its neighbour, or Add files when empty; retry restores the password/start target.
- Screen readers receive file/state names, full-path help and coalesced queue/status notifications without byte-by-byte announcements. Failed entries explicitly say Failed/失败 followed by the error reason.
- Queue actions appear below filenames, with wrapped names, viewport-sized scrolling, system focus visuals and explicit High Contrast system colours.

AGV1, output collision numbering, sequential processing, safe cancellation and settings remain compatible. Passwords and queue state are not persisted.

Planned artifacts: `AegisVault-v2.9-win64.zip`, `AegisVault-v2.9.cdx.json`, and `SHA256SUMS`. See [acceptance](../ACCEPTANCE_2.9.md) for executed checks and outstanding manual coverage. No signed or published artifact is implied by a local build.
