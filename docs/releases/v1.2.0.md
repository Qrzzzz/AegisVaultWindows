# AegisVault v1.2.0

Release date: 2026-09-04.

## Modern Windows interface

The approved spacious layout introduces sidebar navigation, focused page
headings, segmented operation controls, responsive password fields and results
shown after processing. The system title bar is retained. The implementation
uses styled PySide6/Qt Widgets; it is not WinUI or a browser application.

Light, Dark and system appearance can be changed in Settings. Successful saves
apply appearance without replacing workspaces or losing inputs, passwords or
results. File and directory selection use platform-native dialogs. Chinese and
English controls, keyboard navigation and the 600 x 440 minimum size remain.

AGV1 text/file encryption, Base64 text/file conversion, atomic writes,
cancellation and close cleanup keep their existing contracts. No encryption
format or dependency lock changes are included; PySide6 remains at 6.9.3.

## Verification and download

Local UI verification passed 275 tests and 11 Windows-platform workflow tests,
plus light/dark interaction exercises and visual review. These checks use Qt's
test driver and synthetic data; they do not represent human manual acceptance.
The release workflow independently checks source quality, package startup,
dependencies, PE resources, ZIP contents and SBOM, and verifies all public
asset digests and build provenance before publication.

Download `AegisVault-v1.2.0-win64.zip`, extract it and run `AegisVault.exe`.
The other public assets are `AegisVault-v1.2.0.cdx.json` and `SHA256SUMS`.
The executable is not Authenticode-signed. Checksums and GitHub provenance
identify the workflow-built assets.

See [UI acceptance](https://github.com/Qrzzzz/AegisVaultWindows/blob/v1.2.0/docs/UI_ACCEPTANCE.md)
and [UI specification](https://github.com/Qrzzzz/AegisVaultWindows/blob/v1.2.0/docs/UI_SPEC.md).
