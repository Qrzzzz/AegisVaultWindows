# AegisVault 2.8

Local candidate; not yet published. Product version: **2.8**; Windows assembly/PE: **2.8.0.0**.

- File queues show processed/waiting counts independently of the current file's percentage and byte progress. Adding or removing pending files updates the counts without changing the current file's percentage.
- Filter failed files, queue all failures again, or clear completed entries. Filtering never changes processing order; retry preserves successful results; clearing entries leaves output files on disk. Requeued files start with the normal operation button and require passwords again for AGV1.
- Open output details on each successful queue row. File workflows no longer duplicate every output in a separate result editor; text results retain their existing editor and actions.
- Real Explorer drag/drop acceptance is tracked separately from native picker, view-model and backend checks in [2.8 acceptance](../ACCEPTANCE_2.8.md).

AGV1, sequential processing, safe cancellation, collision numbering, settings storage and bilingual controls remain compatible. Queue state is session-only; passwords are not persisted.

Candidate artifacts: `AegisVault-v2.8-win64.zip`, `AegisVault-v2.8.cdx.json` and `SHA256SUMS`. Extract the complete folder before running. This document does not claim remote publication or signing.
