# AegisVault 2.0 — WinUI 3

The complete desktop presentation layer now uses C# / WinUI 3 and Windows App SDK.
The Python Core, AGV1 file format, scrypt and AES-256-GCM behavior remain unchanged.
Product versions now have two components (`2.0`, `2.1`, `3.0`); Windows PE versions use `2.0.0.0`.

- Native Mica, TitleBar, NavigationView and Text / File / Base64 / Settings pages.
- Asynchronous UTF-8 JSON Lines backend with progress, cooperative cancellation and explicit errors.
- Passwords travel over stdin, never command-line arguments. Configuration remains in the 1.x location.
- Chinese and English, system/light/dark themes, native high contrast resources and per-monitor DPI awareness.
- PySide6, Qt frontend, QSS and old screenshot tests removed.

The portable download is `AegisVault-v2.0-win64.zip`. Extract the **entire** folder and run
`AegisVault.exe`; keep its runtime files and `backend` folder together. No installed Python or .NET is required.

AGV1 data and existing configuration remain compatible with 1.x. The retired Qt frontend is no longer maintained.

The release includes a CycloneDX SBOM and `SHA256SUMS`; GitHub build provenance binds all three assets to
the release commit. See `docs/UI_ACCEPTANCE.md` for automated validation and user-reported manual acceptance.
Authenticode signing follows the repository's configured signing policy; build provenance is separate from code signing.
