# AegisVault 2.1 — WinUI 3 polish

Development candidate. User acceptance and release publication are pending.

- Consistent native page headings and a persistent action/status footer, with scrollable input and results.
- Results receive focus after layout; native command overflow supports narrow windows.
- Copy the exact file path, or reuse text output as input for the reverse operation.
- Correct mismatched passwords without retyping both entries; started tasks clear password controls.
- Task controls and progress reflect safe cancellation, and input/result state remains consistent.
- Settings drafts and the Base64 input type survive navigation. Save or discard changes explicitly;
  failed settings writes keep the existing applied settings and the editable draft.
- Retained workflow feedback updates with the selected language.

The local portable candidate is `AegisVault-v2.1-win64.zip`. Extract the complete folder and run
`AegisVault.exe`, keeping the runtime files and `backend` directory together.

AGV1 Core, scrypt, AES-256-GCM, configuration compatibility and the locked dependencies are unchanged.
See [the review](../UI_REVIEW_2.1.md) and [acceptance evidence](../UI_ACCEPTANCE.md) for scope and measured validation.
