# AegisVault v1.0.0

Release date: 2026-09-04

AegisVault 1.0.0 is the first stable public release of the local Windows desktop encryption utility. It provides AGV1 text and file encryption and Base64 encode/decode tools, with all legacy decryption removed.

## Highlights

- A fixed-light native Qt interface with Text, File and Base64 tabs. Empty progress and result areas stay hidden until needed.
- Complete text/file encryption, Base64 conversion, recent files, output reveal, cancellation and bilingual settings workflows.
- Bounded input/KDF validation, atomic file output and settings persistence.
- AGV1-only decryption: no old AES recovery, AK wrapper parser, weak legacy key derivation or compatibility switch.
- Hash-locked dependencies, Python 3.11/3.12/3.13 checks, dependency scanning and CodeQL, plus workflow-built and attested release assets.

## Downloads

- `AegisVault-v1.0.0-win64.zip` - standalone Windows x64 build. Extract the ZIP and run `AegisVault.exe`.
- `AegisVault-v1.0.0.cdx.json` - CycloneDX 1.6 software bill of materials for the locked runtime closure.
- `SHA256SUMS` - SHA-256 digests for the ZIP and SBOM.

Use the assets attached to this GitHub Release. The repository's `release/` directory contains historical binaries, not this workflow-built release. This release is not Authenticode-signed; verify the checksums and GitHub build provenance before running it.

## Security Scope

- Modern text encryption writes `AGV1.` tokens.
- Modern file encryption writes chunked `.agv` containers.
- New encryption uses scrypt and AES-256-GCM with per-encryption random salt.
- Legacy AES text/files and AK wrappers are rejected; old-format recovery is not available.

AegisVault data is locally encrypted with documented design and tests, but not independently audited.

## Compatibility

- Existing `AGV1.` text tokens remain supported.
- Existing `.agv` file containers remain supported.
- Breaking change: legacy AES Encryption System text/files and AK wrappers can no longer be decrypted, even with the original password. Old settings cannot re-enable this removed feature; preserve original data and backups.

## Verification

The release verification command is:

```powershell
.\scripts\verify_release.ps1 -Build -Zip -InstallDependencies
```

That command compiles source, tests and release scripts; runs Ruff, mypy and pytest with coverage; performs source and packaged headless smoke tests; builds and audits the Windows executable; and creates the ZIP, CycloneDX SBOM and `SHA256SUMS`. The GitHub Release workflow additionally binds an annotated tag to the source commit, attests every public asset and verifies the exact draft asset set before publication.

## Known Limitations

AegisVault does not protect against malware, clipboard monitoring, screenshots, screen recording, weak passwords, plaintext backups, compromised machines, or lost passwords. File names and filesystem metadata may still reveal sensitive context.
