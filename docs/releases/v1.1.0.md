# AegisVault v1.1.0

Release date: 2026-09-04.

The three workspaces now use ordinary Windows Qt forms: compact mode controls,
grouped inputs and options, an operation row followed by progress/errors/results,
and selectable output paths. Text input and results share the available height;
file forms keep their natural height. Small windows scroll their content while
the main operation remains reachable.

The application requests a fixed light scheme while retaining the Windows
platform palette, system font and native controls. It no longer replaces that
palette with QStyle's generic classic palette. PySide6 remains locked at 6.9.3.
File and folder selection retain standard Qt dialogs so they remain light even when Windows is dark.

AGV1 text/file encryption and decryption, password confirmation, Base64 text/file
conversion, copy/clear/use-as-input, drag and drop, progress/cancel, recent files,
output preview/reveal, overwrite warnings and Chinese/English settings remain.
The Base64 file workspace now shows its output folder and overwrite warning too.
Result actions that alter the workspace are disabled while a task runs.

Core cryptography, KDF limits, AGV1 format, atomic output protection, cancellation
cleanup, task ids and stopped-thread completion are unchanged. No retired AES,
AK, recovery or theme-selection entry is restored. The persisted theme field
retains its existing compatibility handling.

The release contains `AegisVault-v1.1.0-win64.zip`, `AegisVault-v1.1.0.cdx.json`
and `SHA256SUMS`. Extract the ZIP and run `AegisVault.exe`. The executable is
not Authenticode-signed; verify the checksums and GitHub build provenance.

Local verification passed compilation, Ruff, mypy, all 270 tests with 88.36%
coverage, dependency audit, packaged startup and ZIP/PE/resource/SBOM audits.
Windows 11 interaction checks covered real AGV1 and Base64 text/file round
trips, Chinese/English settings, retained results, long paths, light file
selection, output reveal and the 600 x 440 minimum window. Service-backed
tests covered cancellation and close/wait cleanup. Fixed-DPI checks used
observed device-pixel ratios 1.75 and 2.625; dynamic monitor migration was
not part of the local acceptance.

The release workflow rebuilds the tagged source, attests all three public
assets, then downloads and verifies the draft assets before publication.
See the [UI specification](https://github.com/Qrzzzz/AegisVaultWindows/blob/v1.1.0/docs/UI_SPEC.md)
and [QA checklist](https://github.com/Qrzzzz/AegisVaultWindows/blob/v1.1.0/docs/QA_CHECKLIST.md)
for the maintained behavior and verification commands.
